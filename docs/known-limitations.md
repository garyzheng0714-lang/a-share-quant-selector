# 已知限制和仓库外待办

更新时间：2026-07-23。

## 必须在仓库外完成

### 数据重建

旧数据曾存在真实性风险。系统现在会拒绝模拟数据，但不会自动证明已经落盘的旧 CSV 是真实数据。恢复研究或无人值守模拟盘前，必须在隔离目录中从至少两个可信来源全量重建，验证 manifest 和抽样对账后才可发布。旧训练结果、回测报告和胜率不得继续作为证据。

## 数据与交易边界

- 历史退市证券、每日行业成分、完整公告正文/精确发布时间、实时停复牌事件和上市会话并非所有日期都能从当前公开源完整重建。强制 PIT 路径会在证据不足时拒绝样本，这会降低覆盖率。
- 现有单个最新快照中的前复权历史不能证明过去每个信号日当时可见的价格。训练器现在要求每行 `feature_snapshot_id == reference_snapshot_id`；逐日可信历史快照未重建前，自动进化会明确跳过训练，而不是把当前复权曲线当成发布证据。
- 模拟盘使用日线开盘价和日内 high/low/volume 近似成交，无法重建集合竞价队列、部分成交、盘中临停、逐笔冲击成本和真实券商费率。
- 历史模拟成交/NAV 如果没有快照和成交规则版本，会被保留但阻止生产启动；必须归档旧账本并从可验证的新账户开始，不能将旧数据追认为可发布证据。
- ST 5%、创业板/科创板 20%、北交所 30%和历史上市初期制度已编码，但证券名称、上市会话或制度时点无法证明时会 fail closed。
- 外部行情、交易日历、公告源和 LLM 都可能不可用。决策应转为 observe/unavailable，而不是使用旧数据或猜测。

## 模型证据

- Super B1 是可复现规则 baseline，不是稳定 alpha 或收益保证。
- 当前 market 模型的精确语义是“已经出现 B1 信号的日子里，候选质量是否达标”，不能宣称它预测整个市场。
- 新完整 policy 需要至少 6 个独立前向月、统计功效、数据/源码/模型产物哈希、服务器复验和双人审批。没有这些证据时只能 shadow 或 baseline-only。
- 模拟盘运行时间短时，短期盈亏不能用来宣称模型有效。

## 工程上限

- SQLite 只适用于当前单机、单行情/决策 writer、低并发负载；operations DB 仍有单 Web 进程与 worker 的短事务竞争。需要多 Web/worker 进程、多机高可用或高写入吞吐时必须迁移 PostgreSQL/专用队列。
- 管理员只能原子取消 queued 任务；Python 中已经运行的长任务不能被安全地强制中断，接口会返回 409。需要中止时必须停止专用 worker，并依靠不可变快照/staging、租约和人工核查恢复，不能把仍有副作用的任务标成已取消。
- 发布流程会自动回退应用镜像，不会自动覆盖生产数据库。自动数据恢复可能丢失备份后新写入，所以必须由人员在停止 writer 后核对再执行。
- ECharts 产物 chunk 仍可能超过 Vite 500 kB 建议阈值；这是首屏性能优化项，不影响数据正确性。
- 任务失败和租约耗尽现在会生成不可变 `alert_events`，并可由受保护的 `/api/alerts` 查询；仓库内仍不能代替生产通知渠道接入、送达测试、值班响应，以及备份恢复、外部源故障、磁盘满/SQLite locked 演练。
- 本地环境没有可用 Docker daemon 时，只能静态校验 Compose/workflow；镜像构建、离线传输后的内容 ID 复验、只读挂载、容器 smoke test 和回滚必须在 CI/目标主机实际通过。

## Go / No-Go

| 场景 | 当前判断 |
| --- | --- |
| 代码研究和页面原型 | 可以，必须保留研究声明 |
| 内部人工观察 | 可信数据重建后可以 |
| 无人值守模拟盘 | 只有外部待办、全量门禁和生产演练全部通过后才可开放 |
| 对外推荐或真实交易 | No-Go |
| 宣称模型已稳定自我进化 | No-Go，除非完整发布证据已落账 |
